# Penny 💸

**Penny** is a modern personal finance application designed to help users track their income, expenses, and budgets through a clean and intuitive interface.

## ✨ Features

- Financial overview dashboard
- Income and expense tracking
- Transaction categorization and filtering
- Monthly budget management
- Financial reports and analytics
- Responsive design for desktop and mobile
- Persian language and RTL support

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## 🎯 Project Goals

Penny is a learning-oriented project focused on exploring modern frontend development practices, scalable component architecture, state management, responsive UI design, and Next.js capabilities.
